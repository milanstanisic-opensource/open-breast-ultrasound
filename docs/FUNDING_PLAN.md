# Funding plan

## Status of the numbers

300,000–500,000 € is a provisional multi-year programme ambition. It is not a quotation, not a confirmed cost estimate, and not a statement that the current prototype justifies that amount. No supplier has priced this plan. No institution has agreed to host it. No grant has been awarded.

The existing code is a research prototype: an auditable training pipeline and documentation. It is not a clinical product, and it must not be described as the deliverable that a 300,000–500,000 € campaign has already bought.

## What would have to be priced

Each line needs a written offer or a salary decision before it can be called a budget. Nothing below is a quote.

| Workstream | What the money would be for | Status |
| --- | --- | --- |
| Founder time | Paid time for coordination, documentation, and maintenance by Srdjan Stanisic | A decision, not a hidden salary figure |
| Engineering | Software, tests, reproducibility, and security review | Needs a quote or a scoped contract |
| Clinical work | Radiologist or clinical collaborator time, protocol design | Needs an institutional agreement; no collaborator is named yet |
| Data | Permissions, de-identification, curation, storage agreements | Needs a quote; BUSI alone is not a clinical validation set |

| Infrastructure | Compute and storage for experiments | Needs a quote |
| Quality and regulatory activity | Only if a later stage is justified: quality system, clinical evaluation, regulatory advice | Not started. The ambition does not guarantee authorization |
| Maintenance | Dependency updates and issue response after a public release | Ongoing and easy to under-budget |

## What a partial amount can still deliver

- A small amount: finish a documented BUSI baseline, publish the code, and stop. No clinical claim.
- A middle amount, if a partner exists: one pre-specified retrospective evaluation on a second dataset, including a statistician's time. Still not a device.
- The full provisional range: only a multi-year programme if the quotes and the partners exist. It is an ambition to be checked against those quotes, not a promise that every stage in the roadmap will be completed.

If the money received cannot cover the next honest step, the project should narrow the work to the step it can finish and say so in the campaign update.

## If the results do not justify continuing

- Stop the claim that failed.
- Write up the negative or inconclusive result.
- Do not open a new ask for the same claim.
- Deal with unspent funds the way the campaign text promised before the money was collected. That rule has to be written before a campaign starts. This file does not invent a refund policy for a platform that has not been chosen.

## Separation from other work

Money given for Open Breast Ultrasound stays in a separate ledger from any future longevity, bioinformatics, or unrelated software work. It is not a general research fund for later projects. A different project needs its own description and its own ask.

## How to add a payment link later

This repository has no WhyDonate link, no GitHub Sponsors link, and no bank details, because no such account has been created. When an account exists, add the real URL to the README and state who receives the money and what happens to a surplus. Do not imply that a donation is tax-deductible unless a qualified body has confirmed that.
